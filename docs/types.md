### `rissue`

A plugin that gets issues and merge requests from git provider.

Example usage:

```lua
local rissue = require('rissue')
rissue.setup({
    -- your preferred configuration
})
rissue.get_issues("https://github.com/flamfrosticboio/rissue")
rissue.get_merge_requests("https://github.com/flamfrosticboio/rissue")
```

- <details>
  <summary><code>get_issues</code>: <code>function(remote: string|rissue.ProviderInfo|rissue.RemoteInfo, opts: (table|table&lt;string, table?&gt;)?): rissue.Issue[]?, string?</code> – Gets issues from the url, remote info or provider info</summary>

  If the provided remote is a `string` (url) or `rissue.RemoteInfo`, then the
  `opts` arg requires specifying the provider name inside a table.

  Example:

  ```lua
  --- Passing opts as `string` or `rissue.RemoteInfo`
  rissue.get_issues("https://github.com/flamfrosticboio/rissue.git", {
    github = { max_items = 50 },
    gitlab = { max_items = 500 },
    --- gitea and forgejo may use default/user settings
  })

  --- Passing opts as `rissue.ProviderInfo`
  local info, err =
    rissue.get_provider_info("https://github.com/flamfrosticboio/rissue.git")
  assert(info, err)
  assert(info.name == "github", "Not a github provider")
  --- Now we know that info is specifically github
  rissue.get_issues(info, { max_items = 50 })
  ```

  </details>

- <details>
  <summary><code>get_merge_requests</code>: <code>function(remote: string|rissue.ProviderInfo|rissue.RemoteInfo, opts: (table|table&lt;string, table?&gt;)?): rissue.MergeRequest[]?, string?</code> – Gets merge requests from the remote url, remote info or provider info</summary>

  If the provided remote is a `string` (url) or `rissue.RemoteInfo`, then the
  `opts` arg requires specifying the provider name inside a table.

  Example:

  ```lua

    github = { max_items = 50 },

  })

  --- Passing opts as `rissue.ProviderInfo`

    rissue.get_provider_info("https://github.com/flamfrosticboio/rissue.git")
  assert(info, err)
  assert(info.name == "github", "Not a github provider")

  ```

  </details>

- <details>
  <summary><code>get_provider_info</code>: <code>function(remote: rissue.RemoteInfo, opts: table&lt;string, table?&gt;?): (rissue.ProviderInfo)?, string?</code> – Gets the provider info from remote info or remote url.</summary>

  Example:

- <details>
  <summary><code>api_version</code>: <code>"2022-11-28"|"2026-03-10" | false</code> – Override the api version to be used. Most commonly used when doing requests like <code>get.issues()</code> or <code>get.merge_requests()</code></summary>

  - `{repo}` - Repository name

  See the default settings for examples.

  </details>

- `fetch_delay`: `integer` — The delay between fetching in each endpoints/pages

  performing pagination requests in github. Limit=100 (enforced by github)
- <details>
  <summary><code>max_items</code>: <code>integer</code> – Limits how many items will be fetched and rendered.</summary>

  Note: This does not guarantee the output size of the result to be exactly
  `max_items` and may have more items than requested

  </details>

- <details>
  <summary><code>media_type</code>: <code>"full"|"html"|"raw"|"text"</code> – The type of media to request from issues and pull requests.</summary>

  Attaches a header to the requests:

  ```text
  -H "Accept: application/vnd.github.<media_type>+json"
  ```

  Options:
  - "raw" -- Enables `body` in the api response
  - "text" -- Enables `body_text` in the api response
  - "html" -- Enables `body_html` in the api response
  - "full" -- Combination of `raw`, `text`, and `html`.

  _Note: It is not possible to access to `body_text` and `body_html` when `full`
  is selected. Enable the `store_raw` option instead and access it from raw
  response_

  See more on [github docs](https://docs.github.com/en/).
  - [Issues](https://docs.github.com/en/rest/issues/issues)
  - [Pull Requests](https://docs.github.com/en/rest/pulls/pulls)

  </details>

- `store_raw`: `boolean` — Store the raw response from the server in the results

  ```lua
  local done = false

    done = true
  end)

  --- check condition for every 5 seconds. Timeout is 1 minute

  ```

  `error()`), use `process.try_stop_current_wait()`

  state is tied to luv (e.g. reading a file, finishing a process).

  Example:

  ```lua

    --- do uv readfile
    done = true
  end)

  process.wait(function() return done end, -1)
  ```
